Week 1 - Data Cleaning and Preprocessing

Project Overview

This project is part of my Data Science internship. In Week 1, I worked on cleaning and preprocessing the Titanic dataset using Python and Pandas.

Tasks Performed

- Loaded and explored the dataset
- Checked unique and invalid values
- Identified missing values
- Detected outliers using the IQR method
- Handled missing Age values using the median
- Handled missing Embarked values using the mode
- Removed the Cabin column due to a large number of missing values
- Checked and removed duplicate records
- Performed categorical encoding
- Applied feature scaling
- Performed a final data quality check
- Exported the cleaned dataset

Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

Dataset

Titanic Dataset

## Output

The cleaned dataset was saved as `cleaned_titanic.csv`.
