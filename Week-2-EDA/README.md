
# Week 2 - Exploratory Data Analysis and Visualization

## Project Overview

This project is part of my Data Science internship. In Week 2, I performed Exploratory Data Analysis (EDA) on the cleaned Titanic dataset using Python.

The main goal was to understand the data, find useful patterns, and study the relationship between different passenger features and survival.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed

- Basic statistical analysis
- Age and fare distribution
- Gender and passenger class analysis
- Gender vs survival
- Passenger class vs survival
- Age vs survival
- Fare vs survival
- Embarkation vs survival
- Multivariate analysis
- Correlation heatmap
- Survival rate by gender
- Survival rate by passenger class
- Survival rate by gender and passenger class
- Identification of key findings and patterns

## Key Findings

The analysis showed clear differences in survival outcomes based on gender and passenger class. Female passengers generally had higher survival rates, while first-class passengers had better survival outcomes compared with lower classes.

The fare distribution was also right-skewed, with most passengers paying relatively lower fares and a smaller number paying higher fares.

## Dataset

The analysis uses the cleaned Titanic dataset prepared during Week 1.

## Conclusion

This project helped me understand how Exploratory Data Analysis and visualization can be used to find patterns and meaningful insights from a real-world dataset.
