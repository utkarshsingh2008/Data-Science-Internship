
# Week 3 - Unsupervised Learning and Clustering

## Project Overview

In Week 3, I worked on customer segmentation using unsupervised learning and K-Means clustering. The Mall Customers dataset was used to group customers based on their age, annual income, and spending score.

## Tasks Performed

- Loaded and explored the dataset
- Checked missing and duplicate values
- Selected suitable numerical features
- Applied feature scaling using StandardScaler
- Used the Elbow Method to analyse the number of clusters
- Used Silhouette Score for additional evaluation
- Applied K-Means clustering with 5 clusters
- Visualized the customer segments using a 3D plot
- Analysed the characteristics of each cluster
- Identified possible business implications

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset

Mall Customers Dataset containing 200 customer records.

## Result

The K-Means algorithm divided the customers into five meaningful groups based on age, annual income, and spending score. The clusters showed different customer spending patterns and can be useful for targeted marketing strategies.
